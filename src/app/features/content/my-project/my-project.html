My Tasks (opens in a new tab)

A responsive web-based task management app for organizing daily tasks and tracking progress.

Features

  • Create and organize tasks
  • Search, filter, and archive tasks
  • Track status, priorities & due dates
  • View progress on a dashboard
  • Angular
  • daisyUI
  • Spring Boot
  • PostgreSQL
